# examples

Worked examples of real Claude Code setups — kept as reference, not as a product.
Each folder shows how a team customized Claude Code with skills, commands, agents,
hooks, routines and automations, with every company-specific value turned into a
question you answer at install time.

- [`patsol/`](./patsol/) — one company's day-to-day setup (PR review, bug triage, Jira sync, work journal). Render it with [`render.py`](./render.py); tests live in [`tests/`](./tests/).
